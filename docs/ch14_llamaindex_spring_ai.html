01 · 과제 개요 및 입출력

제10~13장의 Spring AI RAG와 별도의 Python LlamaIndex(라마인덱스, 문서 검색·질의 프레임워크)를 동일한 문서·질문·임베딩 모델로 비교한다. 제14장은 기존 Java 프로젝트를 수정하지 않고 독립 Python 폴더에서 실행한다.

선수학습제04장 Ollama, 제09장 적재, 제10장 Spring AI, 제13장 평가

이 장의 검색 결과는 독립 메모리 인덱스를 사용한다. Elasticsearch에 저장된 제09장 데이터와 동일 인덱스를 공유하는 실습이 아니다.

해설: llama-index-core는 문서·분할·인덱스 기능, llama-index-embeddings-ollama는 로컬 임베딩 연동 기능을 제공한다. 패키지 버전은 설치 시점에 따라 달라지므로 python -m pip freeze > requirements.lock.txt로 기록한다. 외부 공개 서버에 Ollama API를 무인증 노출하지 않는다.

05 · 전체 Python 코드: ch14_compare.py

아래 코드를 ch14_compare.py로 저장한다. API가 달라질 수 있으므로 설치된 패키지 버전을 함께 기록한다.

from llama_index.core import Document, Settings, VectorStoreIndex
from llama_index.core.node_parser import SentenceSplitter
from llama_index.embeddings.ollama import OllamaEmbedding

# (추가) 공통 임베딩 모델: 제04장과 동일한 bge-m3
Settings.embed_model = OllamaEmbedding(
    model_name="bge-m3", base_url="http://127.0.0.1:11434"
)

# (추가) 교육용 원본 문서: 개인 정보나 실제 사내 자료 미사용
source = [
    ("uart", "UART는 비동기 직렬 통신이다. 시작 비트와 정지 비트를 사용한다."),
    ("pwm", "PWM은 펄스 폭의 듀티비를 바꿔 평균 전력을 제어한다."),
    ("adc", "ADC는 아날로그 전압을 디지털 수치로 변환한다."),
]
documents = [
    Document(text=content, metadata={"doc_id": doc_id})
    for doc_id, content in source
]

# (추가) 짧은 문서의 분할 조건을 고정
splitter = SentenceSplitter(chunk_size=256, chunk_overlap=32)
nodes = splitter.get_nodes_from_documents(documents)
print(f"원본 문서 수: {len(documents)}")
print(f"청크 수: {len(nodes)}")

# (추가) 로컬 메모리 인덱스 구성; OpenAI API 키 불필요
index = VectorStoreIndex(nodes)
retriever = index.as_retriever(similarity_top_k=2)

questions = [
    "비동기 직렬 통신은 무엇인가?",
    "펄스 폭으로 전력을 제어하는 기술은?",
]
for question in questions:
    print(f"\\n질문: {question}")
    for rank, hit in enumerate(retriever.retrieve(question), 1):
        doc_id = hit.node.metadata.get("doc_id", "unknown")
        print(f"{rank}위 | 문서={doc_id} | 점수={hit.score:.4f}")
        print(hit.node.get_content()[:120])

코드 풀이: Document에 원본 ID를 기록하고, SentenceSplitter로 청크를 만든다. VectorStoreIndex가 Ollama 임베딩을 호출하여 메모리에 벡터를 저장한다. retriever.retrieve()는 질문과 가까운 청크를 반환한다. 이 코드는 답변 생성이 아닌 검색 검증에 집중한다.

08 · 검색 결과 평가

제13장과 동일한 기준으로 질문별 정답 문서 ID를 지정한다. 첫 질문의 정답은 uart, 두 번째 질문은 pwm이다. 상위 2개 결과에 정답이 포함되는지 기록한다.

질문정답 ID검색 상위 2개Hit@2
비동기 직렬 통신uart실행 후 기입미검증
펄스 폭 제어pwm실행 후 기입미검증

두 프레임워크를 엄밀히 비교하려면 동일한 원문, 분할 경계, 임베딩 모델, 검색 설정 및 검색 후보 집합을 맞춰야 한다.
