04 · 평가 지표

지표뜻계산 기준
Precision@3 (프리시전, 정밀도)상위 3건 중 정답 비율상위 3건의 정답 수 ÷ 3
Recall@3 (리콜, 재현율)전체 정답을 얼마나 찾았는가상위 3건의 정답 수 ÷ 전체 정답 수
MRR (엠알알, 평균 역순위)첫 정답이 얼마나 앞에 있는가질문별 첫 정답 순위의 역수를 평균

정답 문서가 없는 질문은 이 실습의 Recall 계산 대상에서 제외한다. 실제 평가에서는 별도 정책을 정해야 한다.

06 · 전체 코드: ch13_eval.py

# ch13_eval.py — 표준 라이브러리만 사용, 외부 서비스 없이 재현 가능
from collections import defaultdict
from statistics import mean
from time import perf_counter

# 질문별 정답 문서 ID (가상 데이터)
gold = {
    "q1": {"tech_uart", "tech_serial"},
    "q2": {"erp_purchase"},
    "q3": {"tech_pwm"},
    "q4": {"erp_finance"},
}
# 제12장 검색 결과를 흉내 낸 고정 순위 목록 (실제 검색 아님)
runs = {
    "baseline": {
        "q1": ["tech_pwm", "tech_uart", "erp_purchase"],
        "q2": ["erp_finance", "tech_pwm", "erp_purchase"],
        "q3": ["tech_pwm", "tech_uart", "erp_finance"],
        "q4": ["tech_uart", "erp_finance", "erp_purchase"],
    },
    "candidate": {
        "q1": ["tech_uart", "tech_serial", "tech_pwm"],
        "q2": ["erp_purchase", "erp_finance", "tech_pwm"],
        "q3": ["tech_pwm", "tech_uart", "erp_finance"],
        "q4": ["erp_finance", "erp_purchase", "tech_uart"],
    },
}

def precision_at_k(ids, relevant, k=3):
    # 검색 결과 중 정답 문서 비율 (분모는 k)
    return sum(doc in relevant for doc in ids[:k]) / k

def recall_at_k(ids, relevant, k=3):
    # 전체 정답 문서 중 검색된 비율
    return sum(doc in relevant for doc in ids[:k]) / len(relevant) if relevant else 0.0

def reciprocal_rank(ids, relevant):
    # 첫 정답 문서가 나타난 순위의 역수
    return next((1 / rank for rank, doc in enumerate(ids, 1)
                 if doc in relevant), 0.0)

def evaluate(run):
    rows = []
    for qid, relevant in gold.items():
        ids = run[qid]
        rows.append((precision_at_k(ids, relevant),
                     recall_at_k(ids, relevant),
                     reciprocal_rank(ids, relevant)))
    return tuple(mean(row[i] for row in rows) for i in range(3))

for name, run in runs.items():
    p, r, mrr = evaluate(run)
    print(f"{name:9} P@3={p:.3f} R@3={r:.3f} MRR={mrr:.3f}")

# 출처 검증: 검색된 문서 ID와 답변에 표시한 출처 ID 대조
retrieved = {"tech_uart", "tech_serial"}
cited = {"tech_uart", "unknown_source"}
invalid = cited - retrieved
print("출처 ID 검사:", "통과" if not invalid else f"실패 {sorted(invalid)}")
# 주의: ID가 존재해도 답변 내용의 사실성까지 보장하지 않음

코드 풀이: gold는 정답 집합, runs는 검색 결과 순위다. evaluate()가 각 질문의 지표를 계산한 뒤 평균을 낸다. invalid는 검색 목록에 없는 출처 ID를 검출한다.

07 · 예상 출력과 해설

예상 출력 — 실제 Ubuntu 실행 미검증
baseline  P@3=0.333 R@3=0.875 MRR=0.583
candidate P@3=0.417 R@3=1.000 MRR=1.000
출처 ID 검사: 실패 ['unknown_source']

해설: Candidate는 첫 정답 문서가 모두 1위에 있어 MRR이 높다. P@3는 Baseline이 총 12개 결과에서 정답 4개, Candidate가 5개를 찾아 Candidate가 더 높다. Baseline은 q1에서 두 정답 중 하나만 검색해 R@3 평균이 낮다. 출처 검사 실패는 unknown_source가 검색 결과에 없기 때문이다.

09 · 출처 및 답변 검증

1차 검증은 답변에 기재된 출처 ID가 검색 결과에 포함되는지 확인하는 것이다. 2차 검증은 해당 문서의 실제 문장이 답변 주장을 뒷받침하는지 사람 또는 별도 평가기로 판정한다. 출처 ID 일치만으로 사실성을 확정하지 않는다.
