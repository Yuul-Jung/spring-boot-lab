03배경 개념 — 벡터와 임베딩

Vector(벡터, 크기와 방향을 가진 수치 배열)는 예를 들어 [1, 2, 0]처럼 표현한다. 실제 문장 임베딩은 모델이 문맥을 학습하여 여러 차원의 숫자를 출력한 것이다. 아래의 3차원 값은 계산을 쉽게 보여주기 위한 교육용 수치이며 실제 문장 임베딩이 아니다.

벡터의 각 차원을 사람이 임의로 ‘전압’이나 ‘전류’라고 해석해서는 안 된다. 학습된 임베딩의 개별 차원은 일반적으로 독립된 인간 언어의 의미를 갖지 않는다.

04코사인 유사도 계산

두 벡터 A=[1,2,0], B=[2,4,0]를 사용한다.

cos(A,B) = (A · B) / (||A|| × ||B||)

내적: 1×2 + 2×4 + 0×0 → 10
A의 길이: √(1²+2²+0²) → √5
B의 길이: √(2²+4²+0²) → √20
결과: 10 / (√5 × √20) → 1.0

값의미
1방향이 동일
0직교(방향 유사도 0)
-1방향이 정반대

코사인 유사도는 벡터의 크기보다 방향을 비교한다. 길이가 0인 벡터에는 분모가 0이 되므로 정의되지 않는다.

06전체 Java 코드

CosineSimilarityLab.java · 전체 코드
import java.util.Arrays;

public class CosineSimilarityLab {
    // (추가) 동일 차원의 두 벡터를 비교한다.
    static double cosine(double[] a, double[] b) {
        if (a == null || b == null || a.length != b.length || a.length == 0) {
            throw new IllegalArgumentException("벡터 차원이 올바르지 않습니다.");
        }

        double dot = 0.0;
        double normA = 0.0;
        double normB = 0.0;

        // (추가) 내적과 두 벡터의 길이 제곱을 동시에 누적한다.
        for (int i = 0; i < a.length; i++) {
            dot += a[i] * b[i];
            normA += a[i] * a[i];
            normB += b[i] * b[i];
        }

        // (추가) 영벡터는 코사인 유사도가 정의되지 않는다.
        if (normA == 0.0 || normB == 0.0) {
            throw new IllegalArgumentException("영벡터는 비교할 수 없습니다.");
        }

        return dot / (Math.sqrt(normA) * Math.sqrt(normB));
    }

    public static void main(String[] args) {
        double[] query = {1, 2, 0};
        double[][] docs = {
            {2, 4, 0},   // 같은 방향
            {0, 0, 3},   // 직교
            {-1, -2, 0}  // 반대 방향
        };

        // (추가) 문서별 유사도를 출력한다.
        for (int i = 0; i < docs.length; i++) {
            double score = cosine(query, docs[i]);
            System.out.printf("문서%d: %.3f %s%n",
                i + 1, score, Arrays.toString(docs[i]));
        }

        // (추가) 영벡터 오류 처리 동작을 검증한다.
        try {
            cosine(query, new double[]{0, 0, 0});
        } catch (IllegalArgumentException e) {
            System.out.println("검증: " + e.getMessage());
        }
    }
}

검증: 영벡터는 비교할 수 없습니다.

코드 풀이 — 무엇을 계산하는가

dot은 두 벡터의 내적, normA와 normB는 각 벡터 길이의 제곱을 누적한다. Math.sqrt()로 길이를 구하고 나누면 방향 유사도가 계산된다. docs[0]은 질의와 같은 방향, docs[1]은 직교, docs[2]는 정반대이므로 각각 1, 0, -1이 예상된다.

실제 실행에서 이 결과가 나오지 않으면 코드 복사 누락, JDK 설정, 클래스명·파일명을 확인한다.

08실습 확장 — 검색 순위

문서 3개를 유사도 내림차순으로 정렬하면 문서1 → 문서2 → 문서3이다. 검색 엔진에서는 질의와 문서의 벡터를 비교하여 관련성이 높은 후보를 찾는다. 다만 실제 검색 시스템에서는 코사인 유사도 외에 거리 함수, 키워드 검색, 필터, 재순위화 등이 추가될 수 있다.

질의 [1,2,0]
→
유사도 계산
→
문서1 (1.0)
문서2 (0.0)
문서3 (-1.0)

변형 실습: 질의를 [0,0,1]로 바꾸어 순위가 어떻게 변하는지 예상한 뒤 실행해 확인한다. 이 질의는 문서2와 같은 방향이고 문서1·3과는 직교한다.

09개념 검증과 주의사항

확인 질문정답·해설
벡터 길이가 2배이면 유사도도 2배인가?아니다. 양의 배수는 방향이 같으므로 코사인 유사도 1이다.
유사도 0은 무관한 문장이라는 뜻인가?수학적으로 직교한다는 뜻이다. 실제 문장 의미의 무관함을 확정하지는 않는다.
영벡터는 계산 가능한가?아니다. 분모가 0이 되어 정의되지 않는다.
3차원 숫자를 실제 임베딩이라고 불러도 되는가?이 장에서는 수학 실습용 벡터이다. 실제 임베딩은 모델이 생성해야 한다.

11핵심 정리 및 다음 장

벡터는 숫자 배열이며, 임베딩은 모델이 텍스트 등의 정보를 벡터로 바꾸는 과정이다. 코사인 유사도는 두 벡터의 방향을 비교하여 -1부터 1 사이 값을 계산한다. 다음 제04장에서는 Ollama의 실제 임베딩 모델을 호출하여 텍스트를 벡터로 변환한다.
