01과제 개요 · 입력과 출력

IntelliJ IDEA에서 Java 21 기반 Spring Boot 웹 서버를 만들고, Spring AI의 ChatClient(챗 클라이언트, 대화 모델 호출 도구)로 Ollama의 로컬 언어 모델을 호출한다. 데이터베이스와 RAG 검색은 아직 추가하지 않는다.

입력브라우저·curl에서 전달하는 message 문자열
출력/api/health의 고정 문자열 및 /api/chat의 생성 답변
선수 조건Ubuntu 24.04, JDK 21, IntelliJ, Gradle Wrapper, Ollama와 qwen2.5:3b 모델
산출물Spring Boot 프로젝트, Java 소스 2개, 설정 파일, HTTP 검증 결과

05IntelliJ 프로젝트 생성

  1. IntelliJ → New Project → Spring Boot 또는 공식 Spring Initializr에서 프로젝트 생성.
  2. Language Java, Build Gradle - Groovy, Java 21, Group org.example, Artifact rag-lab.
  3. Dependencies에서 Spring Web 선택. Spring AI 의존성은 아래 Gradle 코드에서 추가한다.
  4. 생성 프로젝트를 IntelliJ로 열고 Trust Project → Gradle 동기화. Gradle Wrapper 파일은 유지한다.

IntelliJ 무료 기능에서 Spring Boot 생성 메뉴가 보이지 않으면 공식 Spring Initializr 웹사이트에서 ZIP을 생성한 뒤 IntelliJ의 Open으로 연다. 아래 예제는 Spring Boot 3.5.6 / Spring AI 1.0.3 조합의 교육용 고정 예시이며, 실제 의존성 해석은 실행 환경에서 검증해야 한다.

07Gradle 의존성 구성

build.gradle 
plugins {
    id 'java'
    id 'org.springframework.boot' version '3.5.6'
    id 'io.spring.dependency-management' version '1.1.7'
}

group = 'org.example'
version = '0.0.1-SNAPSHOT'

java {
    toolchain {
        languageVersion = JavaLanguageVersion.of(21)
    }
}

repositories { mavenCentral() }

ext {
    set('springAiVersion', "1.0.3")
}

dependencies {
    implementation 'org.springframework.boot:spring-boot-starter-web'
    implementation 'org.springframework.ai:spring-ai-starter-model-ollama'
    testImplementation 'org.springframework.boot:spring-boot-starter-test'
}

dependencyManagement {
    imports {
        mavenBom "org.springframework.ai:spring-ai-bom:${springAiVersion}"
    }
}

tasks.named('test') { useJUnitPlatform() }

코드 풀이 — Spring Boot 플러그인은 실행 가능한 애플리케이션을 빌드하고, Spring AI BOM(봄, 의존성 버전 묶음)은 Spring AI 모듈 간 버전을 정렬한다. spring-ai-starter-model-ollama는 Ollama 연결에 필요한 Spring AI 자동 구성을 제공한다. Java 21 툴체인을 고정한다.

08Java 소스 작성

RagLabApplication.java 
package org.example.raglab;

import org.springframework.boot.SpringApplication;
import org.springframework.boot.autoconfigure.SpringBootApplication;

// Spring Boot 자동 구성 및 컴포넌트 탐색의 시작점
@SpringBootApplication
public class RagLabApplication {
    public static void main(String[] args) {
        SpringApplication.run(RagLabApplication.class, args);
    }
}
ChatController.java 
package org.example.raglab;

import org.springframework.ai.chat.client.ChatClient;
import org.springframework.web.bind.annotation.GetMapping;
import org.springframework.web.bind.annotation.RequestParam;
import org.springframework.web.bind.annotation.RestController;

// HTTP 요청을 Ollama 대화 모델에 전달하는 실습용 컨트롤러
@RestController
public class ChatController {
    private final ChatClient chatClient;

    // Spring AI가 등록한 ChatClient.Builder를 주입
    public ChatController(ChatClient.Builder builder) {
        this.chatClient = builder.build();
    }

    // 입력: GET /api/chat?message=안녕하세요
    // 출력: 로컬 LLM이 생성한 문자열
    @GetMapping("/api/chat")
    public String chat(@RequestParam(defaultValue = "안녕하세요") String message) {
        return chatClient.prompt()
                .user(message)
                .call()
                .content();
    }

    // LLM 없이 HTTP 서버만 먼저 확인
    @GetMapping("/api/health")
    public String health() {
        return "Spring Boot HTTP OK";
    }
}

코드 풀이 — @SpringBootApplication은 애플리케이션을 시작한다. @RestController는 HTTP 응답을 반환한다. ChatClient.Builder는 Spring이 주입하며, prompt().user(message).call().content()는 질문을 보내 생성된 답변 문자열을 가져온다. 외부에서 전달한 입력은 반드시 서버 측 검증과 접근 제어를 추가한 후 운영 환경에 사용한다.

09Ollama 연결 설정

src/main/resources/application.properties 
spring.application.name=rag-lab
server.port=8080

# Ollama 로컬 API 접속 주소
spring.ai.ollama.base-url=http://localhost:11434
spring.ai.ollama.chat.options.model=qwen2.5:3b
spring.ai.ollama.chat.options.temperature=0.2

코드 풀이 — Spring AI는 로컬 Ollama 서버의 11434 포트에 접속한다. 모델명은 4절에서 내려받은 모델과 동일해야 한다. temperature는 생성 답변의 무작위성을 조절한다. API 키를 사용하지 않는 로컬 실습이지만 Ollama 서비스를 외부 네트워크에 무방비로 공개하지 않는다.

코드 풀이 — ./gradlew는 프로젝트에 포함된 Gradle 버전을 사용한다. 최초 실행에는 Maven Central과 Gradle 배포 서버 접속이 필요하다. 서버를 종료하려면 실행 중인 터미널에서 Ctrl+C를 누른다.

11HTTP 기능 검증

새 Ubuntu 터미널 
# 모델을 사용하지 않는 서버 상태 점검
curl -sS http://localhost:8080/api/health

# 한글 질문 URL 인코딩 후 로컬 모델 질의
curl -sSG 'http://localhost:8080/api/chat' \
  --data-urlencode 'message=RAG를 한 문장으로 설명해 줘'
예상 출력 (모델 응답은 실행마다 달라질 수 있음)
Spring Boot HTTP OK

RAG는 외부 문서를 검색해 그 내용을 바탕으로 답변을 생성하는 방식입니다.

코드 풀이 — 첫 요청은 웹 서버만 검증한다. 두 번째 요청은 --data-urlencode로 한글 문자열을 안전하게 인코딩하여 전달하고, Spring AI가 Ollama에 요청을 보내는 전체 경로를 검증한다. 모델 응답의 내용은 고정값이 아니다.

13핵심 정리 및 다음 장
