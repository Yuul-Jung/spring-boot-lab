00개요 및 입력·출력

제05장의 Java 메모리 벡터 검색은 프로세스를 종료하면 데이터가 사라집니다. 이번 장에서는 PostgreSQL(포스트그레스큐엘, 관계형 데이터베이스)에 pgvector(피지벡터, 벡터 확장)를 추가하여 벡터를 영구 저장하고 코사인 거리로 검색합니다.

입력Ubuntu 24.04, Docker Engine + Compose, Java 21, 3차원 실습 벡터
출력영속 DB, 문서 테이블, 검색 순위, Java JDBC 검색 결과
완료 기준재시작 후 데이터 보존 및 SQL·Java 동일한 1위 문서 확인

실습의 3차원 벡터는 계산 확인용입니다. 실제 bge-m3 모델의 임베딩은 1024차원이며, 두 벡터를 혼합해서는 안 됩니다.

06벡터 테이블 및 샘플 데이터

SQL을 파일로 저장하여 재현성을 확보합니다. 3차원 벡터를 사용하는 이유는 검색 결과를 손으로 검산하기 쉽기 때문입니다.

init.sql 
-- pgvector 확장 활성화
CREATE EXTENSION IF NOT EXISTS vector;

-- 중복 실행 시 기존 데이터를 지우는 학습용 초기화
DROP TABLE IF EXISTS documents;

CREATE TABLE documents (
    id INTEGER GENERATED ALWAYS AS IDENTITY PRIMARY KEY,
    content TEXT NOT NULL,
    embedding VECTOR(3) NOT NULL
);

INSERT INTO documents (content, embedding) VALUES
('전기 회로 설계', '[1,0,0]'),
('전자 부품 핀 연결', '[0.8,0.6,0]'),
('기계 설비 유지보수', '[0,1,0]'),
('자연어 문서 검색', '[0,0,1]');

-- 인덱스 없이 정확 검색부터 확인
SELECT id, content, embedding FROM documents ORDER BY id;
TERMINAL 
sudo docker exec -i rag-ch06-pgvector \
  psql -U rag_user -d rag_lab < init.sql
예상 출력

DROP TABLE

  1 | 전기 회로 설계     | [1,0,0]
  2 | 전자 부품 핀 연결  | [0.8,0.6,0]
  3 | 기계 설비 유지보수 | [0,1,0]

코드 풀이 — VECTOR(3)은 길이 3의 실수 벡터를 저장합니다. CREATE EXTENSION은 pgvector 연산자를 사용 가능하게 합니다. 이 SQL은 기존 documents 테이블을 삭제하므로 실제 업무 DB에 실행하지 않습니다.

07코사인 거리 검색

search.sql 
-- 질문 벡터 [1,0,0]과의 코사인 거리
SELECT id, content,
       ROUND((embedding <=> '[1,0,0]'::vector)::numeric, 4)
         AS cosine_distance,
       ROUND((1 - (embedding <=> '[1,0,0]'::vector))::numeric, 4)
         AS cosine_similarity
FROM documents
ORDER BY embedding <=> '[1,0,0]'::vector, id
LIMIT 3;
TERMINAL 
sudo docker exec -i rag-ch06-pgvector \
  psql -U rag_user -d rag_lab < search.sql
예상 출력
 id | content           | cosine_distance | cosine_similarity
  1 | 전기 회로 설계     |          0.0000 |            1.0000
  2 | 전자 부품 핀 연결  |          0.2000 |            0.8000
  3 | 기계 설비 유지보수 |          1.0000 |            0.0000

코드 풀이 — pgvector의 <=>는 코사인 거리를 계산합니다. 거리 0은 같은 방향, 1은 직교입니다. 코사인 유사도는 1 - 거리로 계산합니다. LIMIT 3은 상위 세 문서만 반환합니다.

08IntelliJ Java JDBC 연동

IntelliJ에서 별도의 Gradle Java 프로젝트를 만들고 Java 21을 선택합니다. Gradle의 JDBC 드라이버만 추가하므로 Spring AI 없이도 DB 연결을 독립 검증할 수 있습니다. Spring AI VectorStore 연동은 후속 장에서 다룹니다.

build.gradle 
plugins {
    id 'application'
}

repositories {
    mavenCentral()
}

dependencies {
    implementation 'org.postgresql:postgresql:42.7.4'
}

application {
    mainClass = 'lab.ch06.Main'
}
src/main/java/lab/ch06/Main.java 
package lab.ch06;

import java.sql.Connection;
import java.sql.DriverManager;
import java.sql.PreparedStatement;
import java.sql.ResultSet;

public class Main {
    public static void main(String[] args) throws Exception {
        // 로컬 학습용 접속 정보: 실제 서비스에서는 환경변수 사용
        String url = System.getenv().getOrDefault(
            "RAG_DB_URL", "jdbc:postgresql://127.0.0.1:5432/rag_lab");
        String user = System.getenv().getOrDefault(
            "RAG_DB_USER", "rag_user");
        String password = System.getenv().getOrDefault(
            "RAG_DB_PASSWORD", "local_lab_only_change_me");

        // PreparedStatement: 사용자 입력을 SQL 문자열에 직접 붙이지 않음
        String sql = """
            SELECT content,
                   ROUND((1 - (embedding <=> ?::vector))::numeric, 4)
                     AS similarity
            FROM documents
            ORDER BY embedding <=> ?::vector, id
            LIMIT ?
            """;

        try (Connection conn =
                 DriverManager.getConnection(url, user, password);
             PreparedStatement ps = conn.prepareStatement(sql)) {

            // 질문 벡터를 동일한 차원(3)으로 전달
            ps.setString(1, "[1,0,0]");
            ps.setString(2, "[1,0,0]");
            ps.setInt(3, 3);

            try (ResultSet rs = ps.executeQuery()) {
                while (rs.next()) {
                    System.out.printf("%s : %s%n",
                        rs.getString("content"),
                        rs.getBigDecimal("similarity"));
                }
            }
        }
    }
}
TERMINAL · 프로젝트 루트 
./gradlew run
예상 출력
전기 회로 설계 : 1.0000
전자 부품 핀 연결 : 0.8000
기계 설비 유지보수 : 0.0000

코드 풀이 — DriverManager는 DB 연결, PreparedStatement는 매개변수 바인딩, ResultSet은 검색 결과 순회에 사용합니다. ?::vector는 문자열 매개변수를 PostgreSQL 벡터로 변환합니다. Gradle Wrapper는 IntelliJ 프로젝트 생성 시 포함되어야 합니다.
