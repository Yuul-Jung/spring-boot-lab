00배경 개념 — 검색은 어떻게 이루어지는가

Embedding(임베딩, 문장을 숫자 벡터로 변환)을 사용하면 글자 그대로 일치하지 않아도 의미가 비슷한 문장을 찾을 수 있습니다. Cosine Similarity(코사인 유사도, 벡터 방향의 유사성)는 두 벡터의 내적을 길이의 곱으로 나눈 값입니다.

기본 개념: 문서와 질문은 반드시 같은 임베딩 모델로 변환해야 합니다. 임베딩 벡터는 저장할 수 있지만, 메모리 저장소는 프로그램 종료 시 사라집니다.

제05장은 Spring AI의 데이터 저장소 연동에 앞서, 핵심 검색 알고리즘을 순수 Java + Ollama HTTP API로 직접 확인하는 단계입니다. Spring AI의 VectorStore(벡터 스토어, 벡터 저장소 추상화)는 제06장 이후 비교합니다.

05전체 Java 코드 — Main.java

외부 JSON 라이브러리를 사용하지 않기 위해 Ollama의 /api/embed 응답에서 숫자 배열 부분만 엄격하게 추출합니다. 실제 서비스에서는 Jackson 등 검증된 JSON 라이브러리를 사용해야 합니다.

src/main/java/Main.java 
import java.net.URI;
import java.net.http.HttpClient;
import java.net.http.HttpRequest;
import java.net.http.HttpResponse;
import java.nio.charset.StandardCharsets;
import java.time.Duration;
import java.util.ArrayList;
import java.util.Comparator;
import java.util.List;

public class Main {
    // Ollama 임베딩 API 및 모델명
    private static final URI API =
        URI.create("http://localhost:11434/api/embed");
    private static final String MODEL = "bge-m3";

    // 문서와 벡터를 함께 보관하는 불변 레코드
    record Entry(String text, double[] vector) {}
    record Result(String text, double score) {}

    private static final HttpClient HTTP = HttpClient.newBuilder()
        .connectTimeout(Duration.ofSeconds(5)).build();

    public static void main(String[] args) throws Exception {
        // (추가) 검색 대상 문서 5개
        List<String> documents = List.of(
            "전기회로에서 저항은 전류의 흐름을 제한한다.",
            "커패시터는 전하를 저장하는 전자부품이다.",
            "UART는 비동기 직렬 통신 방식이다.",
            "FPGA는 디지털 회로를 재구성할 수 있다.",
            "RAG는 문서를 검색하여 언어 모델 답변에 활용한다."
        );

        // (추가) 최초 한 번만 문서 임베딩 생성
        List<Entry> memory = new ArrayList<>();
        for (String doc : documents) {
            memory.add(new Entry(doc, embed(doc)));
        }
        System.out.println("문서 적재: " + memory.size() + "개");

        // (추가) 질문 임베딩 → 전체 문서 점수 계산
        String question = "직렬 통신은 어떤 방식인가?";
        double[] queryVector = embed(question);
        List<Result> results = new ArrayList<>();

        for (Entry entry : memory) {
            double score = cosine(queryVector, entry.vector());
            results.add(new Result(entry.text(), score));
        }

        // (추가) 유사도 높은 순으로 정렬하고 상위 3개 출력
        results.sort(Comparator.comparingDouble(Result::score).reversed());
        System.out.println("질문: " + question);
        for (int i = 0; i < Math.min(3, results.size()); i++) {
            Result result = results.get(i);
            System.out.printf("%d위 | %.4f | %s%n",
                i + 1, result.score(), result.text());
        }
    }

    // 텍스트 → Ollama 임베딩 벡터
    static double[] embed(String input) throws Exception {
        // JSON 문자열 안의 따옴표, 역슬래시, 제어문자 이스케이프
        String json = "{\"model\":\"" + MODEL +
            "\",\"input\":\"" + escapeJson(input) + "\"}";
        HttpRequest request = HttpRequest.newBuilder(API)
            .timeout(Duration.ofSeconds(120))
            .header("Content-Type", "application/json")
            .POST(HttpRequest.BodyPublishers.ofString(
                json, StandardCharsets.UTF_8)).build();

        HttpResponse<String> response = HTTP.send(request,
            HttpResponse.BodyHandlers.ofString(StandardCharsets.UTF_8));
        if (response.statusCode() != 200) {
            throw new IllegalStateException(
                "Ollama HTTP " + response.statusCode()
                + ": " + response.body());
        }
        return parseFirstVector(response.body());
    }

    static String escapeJson(String value) {
        StringBuilder out = new StringBuilder();
        for (char ch : value.toCharArray()) {
            switch (ch) {
                case '"' -> out.append("\\\"");
                case '\\' -> out.append("\\\\");
                case '\n' -> out.append("\\n");
                case '\r' -> out.append("\\r");
                case '\t' -> out.append("\\t");
                default -> {
                    if (ch < 0x20) {
                        out.append(String.format("\\u%04x", (int) ch));
                    } else out.append(ch);
                }
            }
        }
        return out.toString();
    }

    // /api/embed 응답의 embeddings 첫 번째 배열을 파싱
    // 교육용 숫자 배열 파서: 일반 JSON 파서 대체 용도 아님
    static double[] parseFirstVector(String json) {
        int key = json.indexOf("\"embeddings\"");
        if (key < 0) throw new IllegalArgumentException("embeddings 없음");
        int outer = json.indexOf('[', key);
        int start = json.indexOf('[', outer + 1);
        int end = json.indexOf(']', start + 1);
        if (outer < 0 || start < 0 || end < 0)
            throw new IllegalArgumentException("벡터 배열 형식 오류");
        String[] tokens = json.substring(start + 1, end).split(",");
        if (tokens.length == 0 || tokens[0].isBlank())
            throw new IllegalArgumentException("빈 벡터");
        double[] vector = new double[tokens.length];
        for (int i = 0; i < tokens.length; i++)
            vector[i] = Double.parseDouble(tokens[i].trim());
        return vector;
    }

    // 두 벡터의 방향 유사성 계산
    static double cosine(double[] a, double[] b) {
        if (a.length != b.length || a.length == 0)
            throw new IllegalArgumentException("벡터 차원 불일치");
        double dot = 0, normA = 0, normB = 0;
        for (int i = 0; i < a.length; i++) {
            dot += a[i] * b[i];
            normA += a[i] * a[i];
            normB += b[i] * b[i];
        }
        if (normA == 0 || normB == 0)
            throw new IllegalArgumentException("영벡터");
        return dot / (Math.sqrt(normA) * Math.sqrt(normB));
    }
}
주의: 위 코드는 교육 목적의 최소 구현입니다. 서버 응답 JSON을 문자열 위치로 읽는 방법은 응답 형식 변화에 취약하므로 실제 Spring AI 서비스에서는 JSON 역직렬화와 예외 처리를 사용합니다. 문서가 수백만 건이면 전체 순회 검색 대신 벡터 인덱스가 필요합니다.

07코드 풀이 — 왜 이렇게 작성했는가

코드역할의도
record Entry문서·벡터 쌍 보관문서와 임베딩의 연결 유지
embed(doc)문서 임베딩 생성동일 모델의 벡터 공간에 저장
embed(question)질문 임베딩 생성문서와 직접 비교 가능
cosine(a,b)내적 ÷ 벡터 길이의 곱방향 유사도 계산
sort(...reversed())점수 내림차순 정렬가장 가까운 문서 우선 출력
Math.min(3,...)상위 3개 출력문서 수가 3개 미만이어도 안전
계산의 의미

두 벡터가 같은 방향이면 코사인 유사도는 1에 가깝고, 직교하면 0에 가깝습니다. 임베딩 모델의 의미적 유사도는 이 점수만으로 정답을 보장하지 않습니다. 검색 정확도는 실제 질문·문서 집합으로 평가해야 합니다.

10핵심 정리

메모리 벡터 검색은 문서 임베딩 → 메모리 저장 → 질문 임베딩 → 코사인 유사도 → 상위 K개 반환의 흐름으로 구현합니다. 이 장에서는 실제 벡터 DB나 Spring AI 추상화 없이 검색 원리를 확인합니다.
